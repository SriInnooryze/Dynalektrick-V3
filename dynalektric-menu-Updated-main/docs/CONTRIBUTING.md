# Contributing Guidelines for Dynalektric Frontend

Thank you for contributing to the Dynalektric project.

## Development Workflow
1. Clone the repository and install dev dependencies: `npm install`.
2. Run transpile during development: `npm run build:js`.
3. Verify full static site generation before opening PR: `npm run build`.
4. Ensure all changes adhere to [docs/CODING_STANDARDS.md](file:///c:/Users/SriBalaji/Pictures/dynalektric%203rd/dynalektric-menu-Updated-main/docs/CODING_STANDARDS.md).
